# Adaptation Rules

Use this to adjust the plan without overthinking it.

## Daily Check

- Green: normal tiredness. Do the plan.
- Yellow: poor sleep, heavy legs, mild niggle. Cut duration by 30-50%.
- Red: sharp pain, illness, altered gait. Rest, mobility only, reassess.

## Missed Sessions

- Missed easy day: skip it.
- Missed strength: move it once, then skip.
- Missed long day: do not cram. Replace with 60-90m easy and continue.
- Missed peak weekend: reduce the next week by 20-30%.
- Missed two key weeks: reset the plan before increasing volume again.

## Long Session Rules

- Eat every 30-45m.
- Fix hotspots immediately.
- Stop if pain changes your gait.
- Keep the day after a hard long session easy.
- If the long session breaks you for 3+ days, the next long session was too ambitious.

## Distance Changes

- Green week: increase as planned.
- Yellow week: cut total km by 30-50%.
- Red week: keep only mobility and short pain-free walks.
- Never add missed kilometres to the next week.
